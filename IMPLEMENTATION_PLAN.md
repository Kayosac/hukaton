# Переработка Hakaton: ощущения, код, подача

Ветка `rework/game-feel` поверх единой игры v0.1. Источник правил — Kayospace, Hakaton Concept Doc (`hakaton-f5xwo`). Приоритеты заказчика: **ощущения от игры**, затем **код и архитектура**, затем **UI и подача**. Визуал (модели, арт карт) — позже. Пиксели и дизер сохраняются. Работа только в Unity Editor, без сборок приложения.

## Этапы

1. [x] **Ядро вылазки** (`1367c7a8`). Общий набор `Assets/Feel`: пружины, тряска и FOV-удары камеры, стоп-кадр, пул звуков, затемнения. Рука с веером карт, единая модель полёта для снаряда и пунктира, по одному ассету эффекта на карту. Новый ИИ зверей по темпераментам, отклик игрока на урон и лечение.
2. [x] **Сцена и звук** (`362a83c4`). Новый HUD вылазки, звуковые ассеты для всех событий, озеро и заросли с переходами, трофеи, возвращение домой с затемнением.
3. [x] **Лавка** (`3161615f`). Торг на терпении: скрытый предел, комфортная цена, встречные цены, «последнее слово», уход. Два чередующихся посетителя, горячие клавиши, колокольчик, голоса, монеты, кошелёк со счётчиком, часы в конце смены. Уход в лощину через титр.
4. [x] **UI** (`391c40d7`, `125804ef`). Пауза «…» перед ответом посетителя, подсказки клавиш, цвет реплики по настроению. Текст не масштабируется (`TextPunch`). Раскладка подсказок и строки выручки, описания карт без дублей чисел, метки зверей не закрывают экран.
5. [x] **Эффекты Retro Arsenal** (`737025e7`, `dc3fbb59`, `dc8f867d`, `97756656`). Пак закоммичен. Удары карт, смерть, пыль, подбор, возврат домой, звёзды оглушения, пламя зарослей, лучи над находками, монеты продажи и конфетти цели — варианты префабов пакета со звуком игры. Эмодзи-реакции не используются.
6. [x] **Чистка кода** (`9656c5b4`, `4fdf4451`, `97756656`). Удалены тестовый двор торговли, автономный режим мастерской, склад добычи в колодах, устаревшие сцены, префабы, материалы и данные. Мастерская переписана читаемо, код колод отформатирован.
7. [x] **Тесты и документация** (`a0887b4d`, `09fc1ef7`, `e00f610c`). Модель полёта (EditMode), сквозной смоук-тест в реальной сцене (PlayMode). Мост редактора дожидается PlayMode-результатов после перезагрузки домена. README модулей переписаны. Временные авторские скрипты удалены.

## Дальше

- Плейтест с заказчиком: размеры эффектов, громкость, баланс торга и боя.
- Визуал: руки и мира (Blender), арт карт под актуальные названия и эффекты (Лёд, Импульс, Лечение показывают старые).
- Голоса зверей пока синтетические.

## Правила

- Сцена и префабы — источник структуры. Во время игры создаются только экземпляры готовых префабов.
- Шрифты Ithaca 32 / Pixeloid Sans 18 как bitmap TMP, Constant Pixel Size, без дробного масштаба и поворота текста.
- Временные авторские скрипты удаляются после использования. Изменения пользователя в `AGENTS.md` и папка `output/` в коммиты не попадают.
