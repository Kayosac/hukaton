# Старая пасека — документация уровня

Версия 1.1 · 9 ноября 2026. Подробный проект первого полноценного уровня Hakaton, подготовленный по Kayospace, актуальному коду и ассетам проекта, а также уточнениям владельца игры.

**Основной документ:** [LEVEL_DESIGN.md](LEVEL_DESIGN.md). **Для чтения и печати:** [PDF](../../../output/pdf/OldApiary-Level-Design-RU.pdf). **Полный комплект:** [ZIP](../../../output/old-apiary-level-design-v1.1.zip).

Локация 150 × 120 м содержит 22 основные точки, 18 преград, пять мостов, ручей, северную реку, озеро и сток. Цель знакомства — 20–30 минут суммарно за несколько вылазок, с высокой плотностью решений. Геометрия и баланс здесь имеют статус предложения для блокаута. Проверки Unity и плейтесты перечислены как будущая работа, а не как выполненные испытания.

| [validation.json](data/validation.json) | Выполненные проверки документации и их границы |
| [build-manifest.json](data/build-manifest.json) | Состав и контрольные суммы сборки PDF |

В `level-plan.json` координаты `x/y` заданы в метрах на плане, `height` — высота пола относительно озера. Unity-преобразование: `(Xplan, height, 120 − Yplan)`. `lx/ly` — положение подписей, а не отдельные игровые объекты. `roads` содержат SVG-путь и ID связанных точек; они задают схему маршрута, не готовый сплайн или NavMesh. Относительные пути в `source-audit.json` отсчитываются от папки этого README.

Ключевые зависимости реализации: проверка стен при подборе, сегментация водных препятствий, фактическая проходимость воды ценой здоровья, навигация существ по временным путям, награда тролля, сложение прыжка с Импульсом и тайминг Гриба с Луной. Подробности и рабочие альтернативы описаны в главе 15.

## Обновление документа

Редактировать `LEVEL_DESIGN.md`, соответствующие записи JSON и затронутые схемы согласованно. PNG — экспорт SVG, а не отдельный вариант дизайна. При смене геометрии проверить номера, высоты, обходы, положение наград и расход карт; затем обновить PDF и отчёт проверки.

Для сборки PDF нужны Python 3, ReportLab, Pillow и шрифт DejaVu Sans с кириллицей. Скрипт ищет шрифт в стандартном Linux-каталоге и в установленном runtime Codex; на macOS также поддержан Arial. Запуск из корня проекта:

```sh
python3 docs/level-design/old-apiary/tools/build_pdf.py
```

Можно передать путь выходного PDF первым аргументом. Для технических схем используется `tools/build_diagrams.py`: дополнительно нужен Poppler (`pdftoppm`); путь к DejaVu Sans можно задать через `DOC_FONT`. Пять карт в `figures/map-*.svg` являются редактируемыми исходниками; их PNG экспортируются с сохранением пропорций в четырёхкратном разрешении. Пересборка технических схем не меняет карты.

После сборки проверить текст PDF и визуально просмотреть все страницы, особенно листы A3, длинные таблицы и разрезы. Автоматическая проверка `tools/validate_document.py` (дополнительно нужен pdfplumber) проверяет состав, ссылки, связность, суммы и границы PDF, но не заменяет визуальный просмотр или тесты Unity.

В ZIP сохранены папки `docs/level-design/old-apiary/` и `output/pdf/`, поэтому ссылки между основным документом, схемами и PDF работают после распаковки. Ссылки на исходный игровой код действуют внутри репозитория; исходные сцены, префабы и закрытая доска Kayospace в архив не копируются. Открывать `LEVEL_DESIGN.md` рядом с сохранённой папкой `figures/`.
