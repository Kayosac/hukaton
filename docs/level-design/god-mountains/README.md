# Горы бога — документация уровня

Версия 1 · 12 ноября 2026. Сюжетный уровень встречи с богом MG01. Он открывается один раз, после цели лавки в 1000 монет.

**Основной документ:** [LEVEL_DESIGN.md](LEVEL_DESIGN.md).

В этой версии главное — пеший маршрут игрока. Путь длиной ≈ 259 м разбит на восемь зон, Z0–Z7:

1. глухой карман;
2. щель под каменной крышей;
3. три одинаковых угла;
4. спуск в горловину;
5. каменная рамка;
6. белая полка в облаке;
7. горло сквозь хребет;
8. площадка над облачным морем.

На площадке открывается вид на бога. После неё по шагам F0–F8 описан финал: край, ладонь, подъём к лицу, разговор и возврат в лавку.

Это предложение для блокинга. Размер, расстояние и поворот бога выставляются после сборки сцены с маршрутом. Блокаут собран в отдельной сцене `hukaton/Assets/GodMountains/Scenes/GodMountains.unity`. Арт окружения, сценарий финала и тексты реплик ещё не сделаны.

## Данные

[data/route.json](data/route.json) — единственный источник геометрии маршрута. В нём:

- узлы N00–N38 с координатами, высотой пола, шириной, зоной и пройденным расстоянием;
- длины зон;
- точка появления, чекпоинты CP1–CP3, рамка S5, устье M, линия края E, кромка, причал D;
- странные моменты S1–S7;
- параметры контроллера игрока;
- требования маршрута к богу.

Координаты плана: `x` — восток, `y` — север, `h` — высота пола от точки появления. В Unity точка переводится как `(x, h, y)` от корня уровня.

## Обновление

Сначала изменить `data/route.json`, затем пересобрать схемы и обновить затронутые места в `LEVEL_DESIGN.md`:

```sh
python3 docs/level-design/god-mountains/tools/build_figures.py
for f in docs/level-design/god-mountains/figures/*.svg; do rsvg-convert -z 1.5 "$f" -o "${f%.svg}.png"; done
```

Нужны Python 3 и `rsvg-convert` (librsvg); шрифт — DejaVu Sans или Arial. Скрипт только рисует схемы, он не создаёт сцену и не меняет проект Unity.
