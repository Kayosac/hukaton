# Пинок — движение стопы

Два промежуточных кадра с изменением положения стопы в голеностопе: первый — более согнутая и укороченная ракурсом стопа, второй — выпрямление к исходному полному удару. Для этих поз применён imagegen с исходным берцем в качестве референса. Это новые ракурсы, поэтому попиксельная идентичность самого берца не заявляется.

- `kick-01-intermediate.png` — первый промежуточный кадр.
- `kick-02-intermediate.png` — второй промежуточный кадр.
- `kick-03-full.png` — исходный финальный удар, файл без изменений.
- `kick-atlas.png` — три кадра слева направо, 3072 × 1536.
- `kick-preview.gif` — движение вперёд и возврат; серый фон только в превью.
- `frames-preview.png` — обзор трёх кадров.

Холст каждого PNG — 1024 × 1536, с прозрачностью. Нижняя часть штанины от Y=1100 до нижнего края во всех кадрах в точности взята из исходника; переход между новым верхом и исходной нижней частью занимает Y=980–1099. Финальный удар сохранён полностью. Сохранённый атлас прочитан обратно и сверён с каждым кадром по RGBA: различий нет.

Для нарезки: Grid By Cell Size 1024 × 1536, Offset 0, Padding 0; общий pivot снизу по центру, Point filtering. Unity-импорт не выполнялся. Метаданные и проверки — `manifest.json`.
