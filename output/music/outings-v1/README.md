# Саундтрек вылазок v1 — 20 треков (2026-11-13)

Фоновая музыка для вылазок: разные места и ситуации, общая эстетика игры — тёмное фэнтези + ретровейв + weirdcore
(плёнка, калимба, флейта, бурдоны, «за стеной»). Всё синтезировано с нуля кодом (numpy/scipy), без сэмплов, CC0 1.0.

Каждый трек — бесшовная петля: хвосты нот, реверберация и «плывущая плёнка» считаются по кругу.
В Unity ставить WAV (у MP3 на стыке щёлкнет): Loop = on, Vorbis, Compressed In Memory, группа микшера Music.
Громкость сведена как фон: RMS от −21 (спокойные) до −18.5 dBFS (драка, погоня), пик ниже −5 dBFS.

## Исходники
`src/synth.py` — инструменты и петлевой буфер, `src/engine.py` — аккорды, лады, мелодии по мотивам, арпеджио, бас,
барабанные сетки, секции, автобаланс слоёв, эффекты. Треки: `src/ost_a.py` (01–05), `ost_b.py` (06–10), `ost_c.py` (11–15),
`ost_d.py` (16–20). Перегенерация одного трека: `cd src && python3 ost_b.py t07` → `ost/out/07_gornyy_pereval.wav`.
Сиды зафиксированы, результат повторяется. `spec.py ost/out/*.wav` — спектрограммы с огибающей громкости.
