# Саундтрек вылазок v2 — ещё 20 треков (21–40), 2026-11-13

Вторая пачка: больше в сторону «Странного» (weirdcore: трубки, плёнка, объявления, каналы ТВ) и быстрые ритмичные
брейкбиты в духе MTV 2000-х и Jet Set Radio, но с нашим weird и тёмным фэнтези (фригийские лады, хоры, клавесин, орган).
Всё синтезировано с нуля кодом (numpy/scipy/numba), без сэмплов, CC0 1.0. Риффы и хуки написаны вручную нотной записью.

Каждый трек — бесшовная петля. В Unity ставить WAV (у MP3 на стыке щёлкнет): Loop = on, Vorbis, Compressed In Memory,
группа микшера Music. Weird-треки сведены как фон (RMS −20…−17.5 dBFS), брейкбиты громче и плотнее (−16.5…−15.5).

## Исходники
`src/engine2.py` — брейки и их нарезка (`make_break`, `chop`), скретчи, формантные выкрики, acid/reese/саб, дисторшн-гитара,
wah, клавесин, слэп, медные стэбы, рингтон, чиптюн, хаммонд, остановка плёнки, перемотка, провалы, DTMF, райзер, компрессор,
нотная запись риффов (`riff`, `chords`, `kit`). Опирается на `engine.py` и `synth.py`.
Треки: `ost2_a.py` (21–24), `ost2_b.py` (25–28), `ost2_c.py` (29–34), `ost2_d.py` (35–40).
Перегенерация: `cd src && python3 ost2_c.py t30` → `ost2/out/30_vedmin_bigbit.wav`. Нужен `numba`. Сиды зафиксированы.
