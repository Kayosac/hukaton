# Музыка лавки — пять вариантов (2026-11-13)

Всё синтезировано с нуля кодом (numpy/scipy), без сэмплов, CC0 1.0. Каждый трек — бесшовная петля:
хвосты нот, реверберация и «плывущая плёнка» считаются по кругу.

| Скрипт | Трек | Что это |
| --- | --- | --- |
| `t1_za_stenoy.py` | 1 «Лавка за стеной» — **в игре** (`Assets/Audio/Music/ShopMusic.wav`) | мрачная колыбельная: 6/8 с хромым 7/8, шкатулка, калимба, пад, часы, радио из подсобки, хор |
| `t2_teply_elt.py` | 2 «Тёплый ЭЛТ» | лаунж 90-х: FM-пиано, бас, щётки, вибрафон |
| `t3_krivoy_vals.py` | 3 «Кривой вальс» | пьяный вальс: туба, балалайка, игрушечное пианино, аккордеон |
| `t4_pylnye_sklyanki.py` | 4 «Пыльные склянки» | эмбиент без ритма: хор, стекло, ветер в бутылках |
| `t5_torg.py` | 5 «Торг» | лоу-фай бум-бэп: нейлон, саб-бас, монеты, свистулька |

Перегенерация: `mkdir -p out && python3 t1_za_stenoy.py` (рядом должен лежать `synth.py`). Сиды зафиксированы.
`spec.py out/*.wav` — спектрограммы с огибающей громкости.
