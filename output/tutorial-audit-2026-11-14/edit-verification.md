ПК — улучшить
Клик по карте: взять в колоду или / оставить дома. / Перетащи одинаковые карты / одного уровня друг на друга: I + I / = II, II + II = III. Бесплатно, две / копии станут одной. / Уровень I–III — сила, ранг — / редкость у гоблина. / Улучшай руку, колоду, время / смены и выносливость. / Коллекция вмещает вдвое больше / копий, чем колода.
Жаровня — удалить
Клик сжигает карту сразу и / навсегда. / Цена: 75% уплаченной за копию / суммы с округлением вверх. / Проверь «НАЛОГ НА ГАЗ». / Сжигание освобождает место в / коллекции. Убрать из колоды — не / значит удалить. / Стартовые карты защищены. / Слияние тоже освобождает одно / место: из двух карт получается / одна.

## Находки

Находки и опасности
Не всё найденное безопасно. Сохраняй добычу возвращением в лавку.
Сундуки
Подойди и нажми E. Монеты сами летят в / походный кошель. «Нюх торговца» помогает / искать сундуки, «Позолота» улучшает / закрытый сундук. / Некоторые сундуки — мимики: при открытии / кусают! Замороженный мимик открывается / безопасно.
Монеты в походе
Найденные монеты попадут в общий кошелёк / при возвращении. При поражении остаётся / половина, с округлением вниз. / Монеты из сундуков не считаются торговой / выручкой и сами не выполняют цель лавки.
Эффекты состояния
Значки под сердцами показывают эффекты. / Яд и огонь отнимают здоровье со временем. / «Лечение» снимает яд; вода и дождь тушат / игрока. / Гниль уменьшает максимум здоровья до / конца вылазки. Возвращение снимает / эффекты.
Проверь руку и сумку
Перетасовка меняет порядок карт в руке: / перепроверь выбор. Кривые руки отклоняют / броски. / Дырявый карман роняет походные монеты / при движении. Вернись за ними: сами назад / они не прилетят.
