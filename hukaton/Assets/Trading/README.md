# Торговля

Лавка — часть игры в `Assets/Game/Scenes/Hakaton.unity`. Помещение, витрина, камеры и подсобка описаны в `Assets/ShopBlockout/README.md`. Здесь — правила торга и код.

## Торг

Источник: фреймы «общий луп» и «торговля» доски Hakaton Concept Doc (Kayospace, `hakaton-f5xwo`) и пресет v0.1.

- Посетитель просит конкретный товар или категорию (только из тех, что лежат на витрине). R — рекомендованная цена, B — стартовая цена сделки (фиксируется в начале), N — текущее предложение посетителя.
- Игрок отвечает одной из пяти цен от B: старт, +5, +15, +25, +50% (клавиши 1–5), соглашается на N (Space/Enter) или отказывает (Backspace).
- При появлении посетитель получает скрытый предел цены и запас терпения. Цена у «комфортной» точки принимается. Комфорт начинается с R или B и каждый раунд смещается на 30% к пределу. До предела цена принимается с убывающей вероятностью, выше предела — никогда.
- Ответ стоит терпения: 1/1/1/2/3 за пять цен (+1 за повтор той же цены). Если требование дороже оставшегося терпения, посетитель уходит. Иначе он называет встречную цену: сдвигается от прошлой к запрошенной на 30–65%, с шансом 20% упирается.
- Терпение на нуле — «последнее слово»: N можно принять, любая новая цена означает уход. Настроение (нейтральное, недовольное, злое) видно по лицу, голосу, цвету реплики и словам; цифры терпения не показываются.
- Первое предложение R посетителю, который спросил цену, продаёт сразу.

Смена 120 с идёт, только пока лавка открыта. На нуле можно закончить текущую сделку, новые посетители не приходят. Свежая добыча из вылазки восстанавливает смену один раз за вылазку. Продажа списывает один экземпляр и начисляет ровно согласованную сумму (сделка проверяется по id и ревизии).

## Ощущения

`ShopFeel` только наблюдает за сессией и ничего не меняет:
- колокольчик двери, голос посетителя по настроению;
- пауза «…» перед ответом: лицо, текст и голос появляются вместе (`TradingPrototype.reactionBeat`);
- при продаже монеты Retro Arsenal у прилавка (фонтан при крупной), удар FOV и кошелёк, набегающий счётчиком;
- при уходе — хлопок и злой возглас; часы в последние 10 секунд; фоновый шум лавки.

Звуки — `Assets/Game/Data/Shop Audio.asset`.

## Код

| Файл | Роль |
| --- | --- |
| `Domain/TradingSession.cs` | Модель без Unity: инвентарь, витрина, смена, посетители, торг, вылазки, сохранение. |
| `Domain/TradeTypes.cs` | Данные и настройки; `CustomerTerms` задаёт конкретного посетителя для тестов. |
| `Runtime/TradingPrototype.cs` | Ввод и цикл лавки: выкладка, открытие, горячие клавиши торга, пауза ответа, передача вылазки игровому циклу (`ExpeditionRequested`). |
| `Runtime/TradingHud.cs` | Обновляет готовые элементы HUD: панель сделки, подсказки клавиш, цвет и подскок реплики. |
| `Runtime/TradingCustomerPresenter.cs` | Два чередующихся посетителя (`SpriteNpcActor`): вход, лицо по настроению, уход. |
| `Runtime/ShopFeel.cs`, `Runtime/ShopAudio.cs` | Звук и эффекты лавки. |
| `Runtime/TradingSceneBindings.cs`, `TradingShopView.cs`, `TradingInteractionTarget.cs` | Ссылки сцены, камеры А/Б, цели взаимодействия. |

Баланс (стартовые цены, пределы, терпение, пресет расхода, смена) — на компоненте `TradingPrototype` в сцене. Тесты: `Tests/TradingSessionTests.cs`, `TradingProgressTests.cs`, `PixelTypographyTests.cs` (EditMode, сборка `Hakaton.Trading.Tests`).
