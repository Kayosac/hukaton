# Подсобка

Службы за занавеской лавки, кроме компьютера (он — в `Assets/Decks`). Подключение — через `ShopBlockout/ShopBackroomServices`.

## Гоблин-карточник (`GoblinCardShop`, `OfferCardView`)

- Верёвка опускает гоблина с картами (`SuspendedGoblin`), на столе — случайная десятка.
- Ранг выбирается с весами 50/30/15/4/1, затем карта этого ранга (`GoblinOffer`).
- Вслепую карта стоит полцены, округление вверх. «Раскрыть все» переворачивает оставшиеся бесплатно, но дальше каждая — по полной цене.
- Первый визит начинается с приветствия и трёх пояснений (по E).
- Снова позвать гоблина можно после вылазки и отработанной смены (`GoblinVisits`).
- Сохраняются прочитанные реплики, ассортимент и раскрытие.
- Голос — грубое торгашеское бормотание на репликах. При покупке он смеётся, когда денег не хватает — фыркает, при раскрытии — торгуется (`Assets/Audio/Sfx/goblin`).
- Купленная карта взлетает к глазам (`CardInspect`, мировая карта поверх кадра): слепая переворачивается в полёте. Зажатая ЛКМ крутит её, клик в любом месте (или E/Esc/ПКМ) отправляет её вниз из кадра «в инвентарь», и стол возвращается.
- Счётчик коллекции «16/100» — как у жаровни: тем же шрифтом, наклонён, у нижнего правого угла ряда и едет за ним, когда ряд смыкается.

## Жаровня (`Brazier`)

- Сжигает копию из коллекции и возвращает 75 % заплаченной цены, округление вверх.
- Стартовые копии из пещеры защищены от сжигания.
- Модель BR01 сделана в Blender по арт-паку (`Art/Brazier`).
- Префаб — `Prefabs/Brazier.prefab`, стоит у задней стены подсобки.
