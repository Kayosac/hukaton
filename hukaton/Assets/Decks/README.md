# Колоды

Модель коллекции, колод и рук плюс мастерская в лавке. Запуск — через игру (`Assets/Game/README.md`).

## Правила

Две независимые колоды: исследование и бой, до 12 экземпляров каждая. Рука — 3 места, каждую можно расширить до 5 у компьютера. Каждая копия карты — отдельный экземпляр со своим уровнем; улучшается конкретная копия. Купленная у гоблина копия попадает в коллекцию, в колоду её включают у компьютера. Деньги общие с лавкой.

В вылазке рука добирается из перемешанного запаса. Брошенные и сброшенные карты обратно не замешиваются. Когда в исследовании кончаются запас и рука, появляется «Пора домой».

## Код

| Файл | Роль |
| --- | --- |
| `Domain/DeckModel.cs` | `DeckWorkshop` (коллекция, составы, покупки, улучшения, руки, сохранение), `Expedition` и `ExpeditionDeck` (колоды на время вылазки), `CardCopy`, `CardSpec`, `LootSave`. |
| `Domain/ThrowPreparation.cs` | Правила одного броска: заряд и подкрутка одним боковым жестом. |
| `Runtime/CardDefinition.cs` | Ассет карты: колода, действие (`CardAction`), сила, цены, арт, акцент, ассет эффекта. |
| `Runtime/DeckPrototypeConfig.cs` | Набор карт и правила (`Assets/Game/Data/Cards.asset`). |
| `Runtime/DeckPrototype.cs` | Мастерская как сервис лавки: открывается у компьютера (колоды и улучшения) или у гоблина (покупка). Игровой цикл начинает и завершает вылазку через `TryDepart` / `CompleteOuting`. |
| `Runtime/DeckCardView.cs`, `DeckRowView.cs`, `DeckViewport.cs` | Плитки коллекции, строки колоды, проверка размера окна. |

Префабы: `Prefabs/DeckWorkshop.prefab` (база), игровой вариант — `Assets/ShopBlockout/Prefabs/ShopDeckWorkshop.prefab`. Арт карт — `Art/`, рубашки — `Art/Backs/`. Тесты — `Tests/EditMode/DeckModelTests.cs`.
