# Компьютер в подсобке

Старый ПК в духе Windows XP. Подключение — через `ShopBlockout/ShopBackroomServices` (поле `computer`). Префаб `Prefabs/BackroomPC.prefab` вложен в `ShopBlockout/Prefabs/MagicalComputer.prefab`.

## Как работает

- **Вход.** По E — быстрое плавное моргание в чёрное. ПК открывается на весь экран: в центре картинка 4:3 во всю высоту, по бокам чёрные полосы. Камера не двигается, модель монитора свою текстуру не меняет.
- **Включение.**
  - Полное, 3 с, под `pc_boot`: искра, луч кинескопа, размагничивание, BIOS с проверкой памяти и писком на 1,5 с, логотип игры с «XP», «добро пожаловать». Бывает при первом входе и после каждой вылазки.
  - В остальных случаях — короткое, 0,5 с (`pc_wake`).
  - Клик, пробел, Enter или E пропускают загрузку.
- **Выход.** Esc, правая кнопка мыши или «Пуск → Выключить»: вспышка, картинка складывается в горящую линию, линия — в точку, точка гаснет (`pc_off`). Потом моргание обратно в лавку. Открытые окна остаются открытыми до следующего короткого включения.
- **Музыка.** Тихая петля `Audio/Music/PcMenuMusic.wav` со звуком телефонной трубки. Звук трубки запечён в файл, поэтому в WebGL всё звучит так же. Музыка плавно вступает только когда загрузка закончилась и рабочий стол готов (после полной загрузки — с начала, после короткого включения — с того же места), при выключении быстро затихает. Источник — второй `AudioSource` на корне префаба, громкость и длительности затуханий — поля `music*` у `PcComputer`.
- **Рабочий стол.** Иконки и меню «Пуск» открывают окна. Панель задач переключает окна. В трее монеты и часы.
- **«Карты».** Сетка всех копий, выглядят как в жаровне.
  - Карты не в колоде полупрозрачные. Клик кладёт карту в колоду или убирает из неё.
  - Перетащить карту на такую же карту того же уровня — мердж (I + I → II, II + II → III). Подходящие пары подсвечиваются, остальные тускнеют.
  - При наведении — жёлтая подсказка: имя, уровень, сила по уровням, описание.
  - Кнопка сортировки переключает по кругу: по порядку → по имени → по уровню → сначала колода → по редкости. Выбор запоминается.
- **«Прокачка».** Большие кнопки с сегментированной полоской в стиле XP. Нажатие покупает следующий сегмент. Сейчас это размер руки и размер колоды; новое улучшение — новый `PcUpgradeTrack`.

## Как устроено

- Интерфейс ПК — обычный UGUI-холст «PC screen canvas» на слое `PC Screen`. Своя камера рендерит его в `Art/PcScreen.renderTexture` (640×480, пиксельные шрифты Ithaca 16 / Pixeloid 9 по сетке). Вёрстка остаётся 640×480, но `CrtScreen` рендерит холст в k раз крупнее (k — целое, по высоте картинки на экране, до 4; `CanvasScaler.scaleFactor = k`), а для камеры ПК держит Render Scale = 1 — так текст, иконки и логотип не мылятся при растяжении кинескопом.
- Полноэкранный холст «PC display» показывает эту текстуру через `Shaders/CrtScreen.shader`: выпуклость, чёткая выборка без мыла, строки развёртки, маска, лёгкое свечение, анимация питания (луч линзой с ореолом, светящиеся кромки, перегрузка яркости при сжатии, точка с бликами). Альфа этого холста и есть моргание.
- Мышь: `CrtRaycaster` ведёт указатель через ту же выпуклость (`CrtScreenMath` повторяет формулу шейдера) и проверяет холст ПК в этом пикселе. Свой курсор рисует `PcCursor` внутри картинки; над картинкой системный курсор скрыт.

| Файл | Роль |
| --- | --- |
| `Runtime/PcComputer.cs` | Вход и выход морганием, включение и выключение, клавиши, звуки. |
| `Runtime/PcBoot.cs` | Временная шкала включения и выключения, панели BIOS, логотипа и приветствия. |
| `Runtime/CrtScreen.cs`, `CrtScreenMath.cs`, `CrtRaycaster.cs`, `PcCursor.cs` | Картинка кинескопа, общая формула искривления, мышь сквозь выпуклость, курсор. |
| `Runtime/PcDesktop.cs`, `PcWindow.cs` | Рабочий стол, окна, панель задач, «Пуск». |
| `Runtime/PcCardsWindow.cs`, `PcCardTile.cs`, `PcTooltip.cs`, `PcSort.cs` | Окно «Карты». |
| `Runtime/PcUpgradesWindow.cs`, `PcUpgradeRow.cs`, `PcUpgradeTrack.cs` | Окно «Прокачка». |
| `Runtime/PcScrollRect.cs`, `PcScrollThumb.cs` | Прокрутка колесом и полоса прокрутки XP. |

Обои рабочего стола — `Art/Ui/pc_wallpaper.png` (импорт: Max Size 256, Point — пиксельные). Остальную графику (`Art/Ui`, логотип — уменьшенная копия `Content/UI/Branding/PenusLogo.png`) рисует `output/pc-computer/make_sprites.py`, звуки `pc_wake`, `pc_off`, `pc_click`, `pc_error` — `output/pc-computer/make_sounds.py`. Тесты — `Tests/EditMode`: сортировка, прокачка, формула стекла.

Отметка уровня на плитке — общий префаб `Decks/Prefabs/CardLevelMark.prefab`.
