# Сборка мира из кусков

Мир каждой вылазки собирается из готовых кусков ручной работы вокруг постоянной стартовой возвышенности. Правила — Kayospace, Hakaton Concept Doc, фрейм «открытый мир v2 · мир из кусков · 10.11.2026». Фиксированная Старая пасека остаётся запасным уровнем.

Во время игры ничего не генерируется, кроме раскладки: куски, края и звери — готовые префабы. Рельеф кусков строится заранее генератором-инструментом и сохраняется ассетами.

## Стандарт куска

- Размер — `WorldAssembler.chunkSize`, рабочее значение 40 × 40 м. Pivot префаба — центр куска на высоте земли 0.
- На каждом крае земля на высоте 0. Середина края шириной `gateWidth` (8 м) свободна для тропы: без камней, воды, зарослей и коллайдеров выше щиколотки.
- Вода не пересекает край и не подходит к нему ближе 3 м.
- Все четыре края одинаковые, поэтому кусок можно поворачивать шагами по 90° (`rotatable`). Если кусок нельзя поворачивать (например, у него есть «вид» на возвышенность), флажок снимается.
- Край, за которым нет соседа, закрывает `borderPrefab`. Он сделан для северного края: pivot в середине края, +Z смотрит наружу из долины.
- Стартовая возвышенность — отдельный кусок в (0, 0), смотрит на север (+Z). Соседи бывают только перед ней. Место появления игрока — `WorldChunk.departurePose`.

## Раскладка

`LayoutGenerator` (сборка `Hakaton.WorldAssembly.Domain`, без Unity) по зерну:

1. Наращивает компактное связное пятно клеток перед возвышенностью: не шире `halfWidth` в каждую сторону и не глубже `depth`.
2. Набирает куски: сначала по одному на каждый обязательный тег (`requiredTags`), затем случайно по весам. Ни один кусок не превышает `maxCount`.
3. Раскладывает куски по клеткам так, чтобы один и тот же кусок по возможности не стоял рядом с собой. Поворот случайный.

Одно зерно всегда даёт одну и ту же долину. Все куски достижимы пешком через общие края.

## Компоненты

| Что | Роль |
| --- | --- |
| `ChunkDefinition` | Ассет куска: id, префаб, `maxCount`, вес, теги, можно ли поворачивать. |
| `WorldChunk` | Корень префаба куска; у возвышенности — `departurePose`. |
| `WorldAssembler` | Собирает долину по зерну под `root`, ставит края, печёт `NavMeshSurface`. Время сборки и запекания — в Console и в `LastInstantiateMs` / `LastBakeMs`. В контекстном меню компонента — предпросмотр в редакторе. |
