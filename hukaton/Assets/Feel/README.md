# Feel — общий набор «сочности»

Сборка `Hakaton.Feel` (Runtime), её используют вылазка, лавка и игровой цикл. Только презентация: ничего здесь не меняет правила игры.

| Компонент | Что делает |
| --- | --- |
| `SpringFloat`, `SpringVector3`, `Ease` | Демпфированные пружины (частота в Гц, коэффициент затухания) с подшагами — устойчивы при любом кадре. |
| `CameraFeel` | Тряска по «травме» (`AddTrauma`, `Sustain`), угловые толчки (`Kick`), удар FOV (`PunchFov`). `FirstPersonView` складывает это с обзором. |
| `TimeFeel` | Стоп-кадр (`HitStop`), замедление, пауза. Единственный владелец `Time.timeScale`. |
| `SfxCue`, `SfxPlayer` | Звук как ассет (клипы, громкость, разброс высоты, 2D/3D, анти-повтор, кулдаун) и пул источников с петлями (`Loop`/`StopLoop`). |
| `ScreenFade` | Затемнение и титр (`FadeTo`, `ShowTitle`). |
| `VfxBurst` | Одноразовый эффект: проигрывает частицы, может следовать за целью (`Follow`), удерживаться (`HoldFor`) и плавно гаснуть (`Release`). Им снабжены варианты эффектов Retro Arsenal в `Assets/Game/Prefabs/Effects/Retro`. |
| `TextPunch` | «Пружинящий» текст для пиксельных шрифтов: подскок и дрожь со сдвигом только на целые пиксели, без масштаба и поворота. |
| `PixelSquare` | Маленький UI-квадрат (прицел в вылазке и в лавке) ровно чётного числа экранных пикселей: 2 × (экранных пикселей на единицу макета `ReferenceUiScale`, округлённых до целого) — 6 px при 1080p; размер в единицах макета задаётся каждый кадр, Pixel Perfect канваса держит края на сетке. |

Сцена: объект «Game feel» с `TimeFeel` и `SfxPlayer`, `CameraFeel` — на камере игрока, `ScreenFade` — префаб `Assets/Game/Prefabs/UI/Screen fade.prefab`.
