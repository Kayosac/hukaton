# Полигон врагов

Открыть `Assets/EnemyDebug/Scenes/EnemyDebug.unity` и нажать Play. Сцена уже сохранена с игроком, плоскостью, запечённым NavMesh, HUD и 15 предпросмотрами в виде экземпляров префабов.

Передвижение — общий FirstPersonPlayer: WASD, Shift, Space и мышь. Escape освобождает курсор; щелчок в Game View захватывает его снова.

Навести центральную точку на предпросмотр:

| Клавиша | Действие |
| --- | --- |
| 1 | Испуг мирного существа / агрессия остальных |
| 2 | Получение урона |
| 3 | Атака, если она есть у существа |
| 4 | Смерть |
| 0 | Исходное состояние |
| E | Создать живую копию игрового префаба в той же точке |
| R | Удалить все живые копии и эффекты, сбросить позы и счётчик урона |

Цифровой блок также поддерживается. Поза остаётся выбранной до следующего нажатия. Исходный вид и смерть автоматически используют задние спрайты при обходе сзади. Предпросмотры не имеют коллайдеров, Rigidbody, NavMeshAgent и игрового ИИ; наведение использует пересечение луча с плоскостью спрайта. Твёрдые препятствия закрывают наведение. Мирные существа не получают выдуманную атаку.

Каждый запуск в Editor сканирует папки из `Data/Enemy Catalogue.asset` (по умолчанию весь Assets), выбирая корневые WorldCreature с настроенными view, idle, body и navigator. Вложенные экземпляры в префабах уровней не считаются отдельными врагами. Каталог исключает собственную папку отладки. Существующие предпросмотры обновляются, новые создаются из сохранённого Enemy Preview, удалённые убираются. Ручная регистрация нового игрового префаба не нужна. Арт без готового игрового префаба не является отдельным игровым противником.

У живых копий работают исходные WorldCreature, физика, навигация, чувства, темперамент, атаки, звуки и эффекты. Здоровье игрока восстанавливается после каждого настоящего попадания, сохраняя отбрасывание и счётчик полученного урона. Поэтому отладка не завершается смертью. Игровой баланс префабов не изменён.

Сцена использует отдельный ExpeditionWorld и отдельную конфигурацию. Неактивный `Isolated model host` хранит только ленивую модель DeckPrototype; его UI Awake намеренно не запускается. Сессия открывается через существующий DepartPrologue без карточной руки. Здесь нет GameLoop, Tutorial, загрузки/записи сохранения или связи с прогрессом магазина. Ссылки мира, игрока, HUD и корней объектов сохранены в сцене. Никакой стартовый скрипт не строит геометрию, камеры или UI.

Все настройки полигона находятся в Inspector у `Debug Session`: каталог, число колонок, шаг, начало сетки, дальность наведения. Настройки персонажа наследуются от общего FirstPersonPlayer через вариант Debug Player. Копии и эффекты находятся под отдельным `Live copies and effects`.

Сцена не добавлена в список сборки игры. Сборка Hakaton.EnemyDebug включается только в Editor / Development Build, autoReferenced отключён. Editor-компонент перед Development Build обновляет только снимок каталога; он не создаёт сцен или префабов. Добавление сцены в обычный release build отклоняется с понятной ошибкой. Для удаления функциональности достаточно удалить `Assets/EnemyDebug` и его `.meta` (а также убрать сцену из собственного development build profile, если её туда добавили). Игровые модули не ссылаются на эту папку.

Проверки: `Hakaton.EnemyDebug.Tests` в EditMode и `Hakaton.EnemyDebug.Tests.PlayMode` в PlayMode. Отчёты фактической проверки лежат вне Assets: `output/enemy-debug/`.
