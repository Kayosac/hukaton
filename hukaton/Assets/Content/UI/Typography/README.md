# Пиксельная типографика

Ithaca — основной выразительный шрифт. Pixeloid Sans Regular — простой шрифт для описаний, подписей и мелкого интерфейса. Оба содержат латиницу и кириллицу, включая Ёё, Іі, Її, Єє, Ґґ, Ўў. Исходные TTF и лицензии сохранены в Fonts.

Готовые TMP Font Assets находятся в Resources/Fonts; материалы — в Materials. Перетащите Prefabs/Ithaca Text или Prefabs/Pixeloid Body на UI Canvas. В TradingHUD уже подключена эта пара, все надписи используют TMP. Шрифт TMP по умолчанию — Ithaca, размер 32.

| Шрифт | Базовая сетка | Размер в HUD | Другие точные размеры |
| --- | --- | --- | --- |
| Ithaca | 16 px | 32 | 16, 48, 64 |
| Pixeloid Sans | 9 px | 18 | 9, 27, 36 |

Атласы статические, 512×512, RASTER без сглаживания, Filter Mode = Point, Wrap = Clamp, без mipmaps. Материал TextMeshPro/Mobile/Bitmap привязывает вершины к экранным пикселям. SDF, мягкие контуры и автоматическое изменение размера выключены. Запечено 963 символа Ithaca и 1010 Pixeloid Sans; динамическое добавление отключено.

Для ровных пикселей оставляйте Transform Scale = 1 и размер шрифта кратным его базовой сетке. Canvas: Screen Space Overlay, Pixel Perfect; Canvas Scaler: Constant Pixel Size, Scale Factor = 1 (или целое увеличение 2, 3). Дробные размеры, Scale With Screen Size, растяжение по одной оси и поворот нарушают равномерную пиксельную сетку. В Game View проверяйте изображение при масштабе 1×: уменьшенный предпросмотр редактора может выглядеть размытым.

HUD закреплён экранными anchors и остаётся в настоящих экранных пикселях. На маленьком окне элементы не уменьшаются автоматически: при необходимости правьте layout или выбирайте другой целый размер. Canvas Overlay рисует текст поверх обработки 3D-камеры.

Проверки в PixelTypographyTests контролируют алфавиты, бинарную альфу атласов, фильтрацию, ссылки материалов и размеры HUD. Сохранённые ассеты работают без генератора и без создания интерфейса во время запуска.

Источники: https://ggbot.itch.io/ithaca-font и https://ggbot.itch.io/pixeloid-font.
