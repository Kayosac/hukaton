# Блокаут лавки

Сцена: `Scenes/ShopBlockout.unity`.

Редактируемая геометрия и префабы: помещение 3,4 × 4,8 м, прилавок напротив входа, отдельная витрина справа в покупательской зоне, подсобка за занавеской, макет компьютера и подвесной гоблин высотой 35 см. Размеры — рабочие значения блокаута.

В `Layout markers` сохранены точки камер А/Б и места покупателя. Камера А — за прилавком; Б — рядом с NPC, фронтально к витрине. Статический спрайт покупателя использует существующий атлас из `Content/NPCs/Peasant`.

Для осмотра в Play используется вариант существующего `FirstPersonPlayer`. Собственных игровых скриптов, UI, тестов и генераторов у блокаута нет. Торговля, смена камер через быстрое моргание, компьютер и вызов гоблина подключаются отдельно.
