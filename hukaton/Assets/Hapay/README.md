# хаPAY

Аукцион коллекционеров на ПК в подсобке (доска KayoSpace «Спецпредметы», блок «Предмет 3 — аккаунт на хаPAY»). Открывается спецпредметом «Аккаунт на хаPAY» — бумажкой прежнего хозяина лавки (Delmon / Del123). Вместо ручной торговли игрок продаёт наборы целиком.

## Как появляется

- Аккаунт — спецпредмет `SpecialItems/Data/Account.asset` (id `hapay_account`, 1500 монет, `unlock: AfterStranger`, `use: NotOnOutings`). На вылазку не берётся: в меню Q и в руке его нет.
- У гоблина-карточника он появляется после Незнакомца (облик кузнеца) в конце смены — когда гоблин на прилавке договорил свои реплики, последняя: «И загляни ко мне. Нашёл тут кое-что от прежнего хозяина.» (`GameLoop.strangerGoblinLines`, в сцене).
- После покупки на рабочем столе ПК, в «Пуске» и на панели задач появляется хаPAY (`PcDesktop.SetAvailable`).

## Лоты

| Что | Где |
| --- | --- |
| Коллекционеры (ник, аватарка, строка, что хочет), числа сайта | `Data/Hapay pool.asset` (`HapayPool`) |
| Состояние сайта: лоты, часы, первый лот, продажи (в сохранении `hapay`) | `HapayMarket`, хозяин — `HapayHost` на объекте сцены «Hapay» |
| Склад + витрина, цены и редкость для сайта | `Game/Runtime/HapayShopStock.cs` |
| Продажа набора в лавке | `TradingSession.SellSet` |
| Окно на ПК | `Computer/Runtime/PcHapayWindow.cs`, `PcHapayLotView.cs`, `PcHapayItemCell.cs`; объект «Hapay window» в `Computer/Prefabs/BackroomPC.prefab` |
| Тесты | `Tests/EditMode/HapayMarketTests.cs`, `Trading/Tests/HapaySetSaleTests.cs` |

- Лот — тематический набор конкретных предметов (обычно 2–5, бывает 7–9, бывает много штук одного). Любые предметы каталога, в том числе ещё не виденные. В пуле 31 коллекционер (первая версия собрана скриптом `output/hapay/src/make_pool.py`, дальше правится в инспекторе).
- На сайте 4 лота. У каждого свой срок: 8 мин для набора из 2 штук … 25 мин для 9 и больше. Часы идут, пока идёт игра — в лавке и на вылазке; стоят на паузе, в главном меню и когда игра закрыта (`GameLoop.TickHapay`, `GamePause.Suspended`). Время вышло или лот продан — на его место приходит новый. Ушедший лот не возвращается ближайшие 5 смен лотов.
- Цена: сумма рекомендованных цен × (1,3 + 0,04 за каждую штуку сверх двух + 0,05 × средняя редкость 0–3), не больше 1,6, округляется до 5 монет.
- Предметы берутся со склада, недостающее — с витрины (на ячейке оранжевая метка). Продать можно только целиком; кнопка «Продать» зелёная, живая только при полном наборе. Продажа сразу, без подтверждения: штамп «ПРОДАНО», монеты (`coins_big`), удар штампа (`impact_paper`), конфетти Retro Arsenal внутри картинки ПК. Деньги идут в кошелёк и в выручку лавки, каждая штука — продажа.
- Первый лот после покупки аккаунта — «верный_покупатель»: собран из того, что у игрока уже есть (до трёх самых дорогих видов по штуке), живёт 25 мин. Если продать нечего, он появится при следующем входе на сайт с товаром.
- Рейтинг Delmon (звёздочки, отзывы) — только для вида.

## Вид

Окно «хаPAY — Гоблин Эксплорер»: адресная строка, шапка с лого (`Art/hapay_logo.png`, вариант 3 с доски), «Вы вошли как Delmon», счётчик посетителей, мигающие «NEW!» и «ЛОТЫ ОБНОВЛЯЮТСЯ!!!», бегущая строка, 4 строки лотов. Аватарки — силуэты на сером (`Art/hapay_avatar_*.png`). Картинки предметов — те же 32-пиксельные значки, что у «Склада» (`Computer/Art/Stock/PcStockIcons.asset`); у предмета без значка — начало названия. Под указателем на предмете — жёлтая подсказка с названием.

Пока окно открыто, вместо музыки ПК играет своя музыка сайта `Audio/HapaySiteMusic.wav` («Купить сейчас!», вариант B «заброшенный сайт», исходник `output/music/hapay`), громкость 0,2.

## Гвоздик

При первом включении ПК после покупки (или после других экскурсий ПК) — своя экскурсия `pc.hapay` (`PcGuide.hapayTour`): значок (игрок открывает сам), лоты, «есть / нужно» и метка витрины, часы, «Продать» (игрок продаёт первый лот сам; если продать нечего — показ призрачным курсором), прощание. Пока она идёт, часы лотов стоят. Esc пропускает только её. Повтор — общей кнопкой «Показать экскурсию снова».

## Читы (F1)

«Аккаунт на хаPAY» — выдать аккаунт; «хаPAY — новые лоты» — все лоты уходят, приходят новые.
