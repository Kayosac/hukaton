Hakaton — веб-сборка

Запуск:
  macOS   — двойной щелчок по start.command (если macOS спросит — «Открыть»).
  Windows — двойной щелчок по start.bat.
Игра откроется в браузере по адресу вида http://localhost:8800/. Окно с сервером не закрывай, пока играешь.

Почему не просто index.html: браузер не запускает такие игры из файла, нужен адрес http://.
Папку целиком можно выложить на любой статический хостинг (itch.io, GitHub Pages и т. п.) — сборка распакуется сама.

Пересобрать: в Unity меню Hakaton → Build → Web (сборка ляжет в Builds/Web рядом с Assets).
